
# CyberGuard AI

## Intelligent Cyber Threat Analysis Expert System

### Project Objective
To develop an AI-powered expert system that analyses
cybersecurity events, identifies suspicious behaviour,
classifies potential cyber threats and recommends
appropriate security measures.

### Technologies
- Python
- Streamlit
- Artificial Intelligence
- Random Forest
- Expert Systems
- Pandas
- NumPy
- Plotly
- Scikit-learn

### Modules
1. Command Dashboard
2. Threat Analysis
3. Threat Intelligence
4. Expert System
5. AI Prediction
6. System Workflow
7. Security Reports
8. Voice Assistant

### Installation

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Run Application

```bash
🔗 **Live Application:** [Launch CyberGuard AI on Streamlit](https://cyber-threat-analyzer.streamlit.app/)
```

### Deployment
Upload the project to GitHub and deploy it
using Streamlit Community Cloud.

### Disclaimer
This application is an academic prototype.
It does not replace production cybersecurity
monitoring or incident-response systems.
